# Automotive-Market-Intelligence
End-to-end automotive valuation pipeline built during the INSTANT Hackathon. Compared Ridge and XGBoost, achieving superior XGBoost performance (R²: 0.98, MAE: 592.05) on 500k+ records. Implemented PriceVsMMR metric, deployed a Streamlit app for real-time inference, and created a Power BI dashboard for market insights.
